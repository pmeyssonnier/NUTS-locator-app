Confidentialité et limites

Confidentialité : seuls les champs Adresse, Numéro, Code postal, Ville et Pays sont envoyés au serveur Nominatim choisi ; noms, prénoms et autres colonnes restent dans votre navigateur. Les réponses du géocodeur et les contours NUTS sont gardés en cache dans ce navigateur (IndexedDB ; bouton « Vider le cache » pour le géocodage) ; la dernière session (données importées et résultats, hors e-mail) y est aussi conservée pour pouvoir être restaurée (bouton « Oublier la session » pour l'effacer) ; le fond de carte charge des tuiles depuis le serveur choisi. Le serveur public Nominatim est limité à 1 requête/s et n'est pas prévu pour du géocodage massif.

    4. Carte

    Légende

    Tactile : glissez pour déplacer la carte, pincez pour zoomer, touchez un point pour afficher sa fiche puis « Voir dans la liste ».

    Clavier (carte active) : flèches pour déplacer (Maj : plus loin) · + et − pour zoomer · 0 ou Début pour tout afficher · Page suivante / précédente pour passer au point suivant / précédent · Échap pour fermer l'info.
